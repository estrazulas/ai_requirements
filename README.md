# ai_requirements

Repositório que centraliza projetos de gestão de requisitos e gestão de projetos com IA usados na Pós-graduação em Engenharia de Software com IA Aplicada (UNIPDS).

## `unipds-gerencia-projetos/`

Repositório da disciplina de **Ferramentas de IA para Gestão de Projetos**, que centraliza os prompts, códigos, dados de exemplo e atividades práticas das demos. Ao longo de 10 módulos, o material constrói um pipeline completo de gestão de projetos assistida por IA sobre um caso único — o **RouteWise**, sistema de gestão de frota com 140 veículos — indo da transcrição de uma reunião de discovery de 35 minutos até um portfólio com OKRs validados, com cada módulo trazendo o system prompt da ferramenta, os dados de entrada usados na demo, o output de referência para comparação e a missão prática em PDF, sobre a stack de Google Gemini (AI Studio), Jira, Slack e códigos em Node.js e Python.
